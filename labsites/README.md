# Controlled lab sites (U11)

Offline test sites for a fictional brand, **Lumina Foundation**, that mirrors the
Isha structure: a foundation, a teacher (Master Orin), a program (Inner Radiance),
a campaign (Save Rivers) and an official donation payee. Every name, payee, page
and image is synthetic (KTD14); no real brand asset is used or redistributed.

The sites are served by nginx (`docker/lab.compose.yaml`) on the internal `bs_lab`
network (`172.31.250.0/24`) and are reachable only in lab mode:

- from the host, through the lab proxy on `127.0.0.1:3129` (`config/lab.yaml`);
- from containers on `bs_lab` (the lab tests' probes).

Production sandboxes and the production egress proxy cannot reach them.

| Site | Hostname | Pattern |
|---|---|---|
| `official` | luminafoundation.test | the brand's confirmed official site |
| `news-critical` | dailyledger-news.test | benign critical journalism with article markup |
| `parody` | lumina-parody.test | benign parody |
| `unrelated-tourism` | lumina-valley-tourism.test | unrelated use of the low-tier keyword |
| `unrelated-lounge` | illumina-lounge.test | keyword inside an excluded word (the "shisha" case) |
| `unrelated-yoga` | sunrise-yoga-studio.test | unrelated yoga studio with a Stripe checkout |
| `typosquat-parked` | luminafoundatoin.test | typosquat parking page |
| `copied-assets` | lumina-foundation-org.test | clone with a re-encoded copy of the official logo |
| `image-only` | orin-relief.test | brand and donation appeal only inside images |
| `js-login` | login-luminafoundation.test | login form built by script |
| `js-payment` | pay-luminafoundation.test | gateway-like script, card fields, UPI QR |
| `donation-fraud` | donate-luminafoundation.test | static appeal, UPI deep link, unknown payee, QR |
| `false-association` | orin-wellness-partners.test | "official partner of Lumina Foundation" |
| `disguised-credential` | lumina-watch-news.test | credential form inside article markup and a parody disclaimer |
| `redirects` | go-luminafoundation.test | meta refresh, script redirect, 302 to metadata and loopback, 302 chain |
| `cloaking` | luminafoundation-gift.test | harmless page for non-browser agents, fraud for Chromium |

Each site's `expected.yaml` names the expected category, priority band, labels,
evidence and the stage expected to detect it (`static`, `media` or `browser`);
U15, U19 and U21 consume it. The lab accepts no submissions (POST returns 405)
and loads nothing from the Internet (the yoga studio's Stripe tag is a static
indicator that the offline lab never fetches).

Images are generated by `generate_assets.py` (see its docstring). The `.test`
TLD is reserved (RFC 6761) and is a known suffix to the matcher, so each lab site
has its own registrable domain like a real registration.

Adding a site: create `labsites/<site>/index.html` and `expected.yaml`, add a
server block to `nginx.conf` and the hostname to `config/lab.yaml`;
`tests/unit/test_lab_fixtures.py` checks they agree.
